# AI Avatar & Video Generator Course

This is a beginner-to-advanced web-based course that teaches you how to create AI avatars, generate videos, and build your own automated AI avatar apps.

## Live Demo
Once deployed via GitHub Pages, access it here:
```
https://yourusername.github.io/ai-avatar-course
```
(Replace `yourusername` with your GitHub username)

## Course Overview
- Avatar creation using AI tools
- Text-to-speech integration
- Video production & editing
- App coding with Python & HTML
- Automation and scaling strategies

## How to Use
1. Clone or fork this repository.
2. Customize or expand the `index.html` file as needed.
3. Enable GitHub Pages from the repository's Settings > Pages tab.

## Tools Used
- OpenAI (ChatGPT, APIs)
- ElevenLabs (voice AI)
- Midjourney / Stable Diffusion (image generation)
- D-ID, HeyGen, Wav2Lip (avatar animation)
- CapCut, OBS, Canva (video editing)
